# UQ 学习计划助手

一个中文优先的课程规划工具。用户可以参考昆士兰大学（UQ）2026 年 Master of Business（项目 5583）及 Master of Commerce（项目 5584）学习计划，按专业查看课程、安排学期，并将计划保存在浏览器中。

> **项目状态：开发预览版。** 本项目不是 UQ 官方产品，也不能确认选课资格或毕业资格。课程要求、先修、不兼容、开课和考核可能因年份、校区或个人情况变化；使用前请核对 UQ 官方资料。

## 功能

- 查看两个学位 1.5 年制和 2 年制的 2026 年官方示例，选择专业方向及入学学期。2027、2028 年使用 2026 年资料作为参考，适用性尚未核实。Commerce 的 1.5 年制双专业暂无官方示例，暂不支持。
- 在选课引导中参考课程类型、历史开课和考核偏好；可将课程拖到学期或在学期间移动。
- 查看已知先修、相斥、专业资格、历史开课及学期负荷提示；复杂或缺失的条件需要人工核实。
- 逐门录入成绩，查看学期与已记录课程 GPA；本地保存计划，支持 JSON 导入导出及浏览器打印为 PDF。
- 查看历史课程考核摘要和对应的官方资料链接。

具体可选配置与限制见 [资料来源和已知限制](docs/DATA_SOURCES.md)。

## 本地运行

需要 **Node.js 22 或更新版本**。应用没有第三方 JavaScript 运行依赖，无需账号或数据库。

在项目文件夹中运行：

```bash
npm start
```

打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。如果端口已被占用，请先检查是否已经有本项目在运行。关闭运行命令的终端会停止网站。

```bash
npm test       # 自动测试
npm run audit  # 批量课程操作测试，结果写入 outputs/internal_testing/
```

保存的计划存储在当前浏览器和网址对应的本地存储中，不会自动同步到其他设备或浏览器。需要跨设备保存或继续编辑时，请使用 JSON 导出和导入；PDF 用于阅读。

## 文件结构

```text
.
├── .github/workflows/    # GitHub 自动测试
├── docs/                 # 数据来源、限制与上传步骤
├── index.html            # 网站入口
├── server.js             # 本地开发服务器
├── src/                  # 页面、规则和运行时课程资料
│   └── data/             # 整理后的课程与历史考核资料
├── tests/                # 自动化测试
├── scripts/              # 数据采集、整理与批量测试脚本
├── outputs/uq_general_electives/
│   ├── assessment-audit.json  # 考核资料核查记录
│   └── offering-audit.json    # 历史开课核查记录
└── resources/            # 本机原始资料说明；原件默认不上传
```

网站运行和自动测试不依赖本地工作簿或 PDF 原件。部分数据重新采集脚本需要网络、Python 依赖和本地工作簿；详见[资料来源](docs/DATA_SOURCES.md)。
